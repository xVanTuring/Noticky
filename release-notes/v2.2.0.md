### New
- **Multi-select group display** — the tray "Display" menu now shows several groups' stickies at once (each group toggles on/off independently), instead of only one group at a time. "Show All Stickies" checks every group.
- **Hide groups from the menu bar** — right-click a group in the manager to keep its notes out of the menu bar list. Hidden groups are marked with an icon in the sidebar.

### Fixed
- **Note content loss in the manager (important)** — editing notes while switching between them in the manager window could write one note's text into another and lose the original. Fixed.
- Clicking a sticky no longer jumps back and forth between virtual desktops (Spaces).
- "Show All Stickies" no longer stays checked after "Hide All Stickies".

### 新增
- **分组显示多选** — 托盘「显示」菜单现在可同时显示多个分组的便签（每个分组独立勾选开/关），不再是一次只能看一组。「显示所有便签」= 全部分组勾选。
- **在菜单栏隐藏分组** — 在管理窗口右键分组，即可把它的笔记从菜单栏列表里隐藏；被隐藏的分组在侧栏有图标标记。

### 修复
- **管理窗口笔记内容丢失（重要）** — 在管理窗口连续切换编辑不同笔记时，可能把一条笔记的内容写进另一条并覆盖原文。已修复。
- 点击便签不再在多个虚拟桌面（Spaces）之间来回跳转。
- 「隐藏所有便签」之后，「显示所有便签」不再错误地保持勾选。
